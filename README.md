# MHAA SPI Contract

Defines clocked, full-duplex word exchange over a configured SPI peripheral. The base covers widths up to 32 bits and a separate eight-bit capability works with packed byte buffers.

Implement `Controller` for the supported word formats and add `ByteExchange` for packed eight-bit buffers when available.

## Where it fits

The SPI Contract defines the interface and observable behavior. A concrete MCU Adapter implements it using Hardware Definitions. The Core consumes a reference to the implementation. Future Devices will bind the selected Adapter to the Core for the application. This project depends on C++11 standard headers.

Add `include/` to the C++11 include path and start with `<spi/controller.hpp>`. The [technical guide](docs/index.md) covers the other public interfaces and integration obligations.

## Generate the API reference

Use Doxygen 1.18.0. From this repository root, create `build/` if it does not exist, then run `doxygen Doxyfile`.

```sh
mkdir -p build
doxygen Doxyfile
```

On PowerShell, use `New-Item -ItemType Directory -Force build` for the first command. Open `build/docs/html/index.html`. Mermaid diagrams render in a browser with access to the Mermaid CDN. GitHub Pages publication runs on published releases and on manual dispatches from `main` once Pages is enabled.
